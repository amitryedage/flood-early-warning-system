# FEWS Client

This is the frontend implementation for the Flood Early Warning System.

## 🚀 Overview
- **Framework**: React 19 + TypeScript
- **Tooling**: Vite
- **Styling**: Tailwind CSS + Framer Motion
- **Maps**: Google Maps JS API

## 🛠️ Setup
1. Ensure the root project dependencies are installed.
2. Configure `.env` with `VITE_GOOGLE_MAPS_API_KEY`.
3. Run `npm run dev`.

Refer to the [Root README](../README.md) for full project documentation and architecture.
